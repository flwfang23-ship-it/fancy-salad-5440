1.1 为什么要做

商户在日常运营中需要将 H5 活动页面通过外部渠道进行推广投放。当前商户每次推广都需要分别生成链接、配置口令、管理投放状态，且一次只能推广一个活动。当商户需要在同一投放场景中同时推广两个活动时，需要分别生成、投放和管理多条链接，用户也无法在同一页面中直接选择活动。

需要一套统一的 H5 外部推广链接管理能力，支持单活动和多活动两种推广模式，让商户在后台一站式完成链接创建、配置、投放和状态管理。

text
改造前

活动 A → 链接 A ─┐
                 ├→ 商户分别投放和管理
活动 B → 链接 B ─┘


改造后

单活动模式：活动 + H5 模板 → 一条推广链接 → 对外投放

多活动模式：活动 A × 推广位 A + 活动 B × 推广位 B + 多活动模板 → 一条推广链接
                ↓
        用户在同一页面选择活动

1.3 最终目标

  • 统一管理推广链接： 商户在后台一站式管理单活动和多活动两种推广链接的创建、编辑、状态切换和删除。
  • 简化多活动配置： 将多活动版位配置从"选平台 → 选活动 → 选推广位"简化为直接填写"密令简版 + 直达链接"，降低商户操作门槛。

2.2 阶段划分与阅读说明

后续正文按照业务实际发生顺序线性展开，不按操作端分别集中介绍。根据当前业务闭环，可划分为：

1. 第一阶段：模板与推广基础准备（主要参与方：SaaS 总后台）：SaaS 总后台准备可推广活动和 H5 模板，模板启用后被客户端新建链接时选择。

H5 模板状态（SaaS 总后台）

状态 业务含义 触发操作 可执行的后续操作

停用 模板暂停用于新建，历史链接不受影响 SaaS 总后台运营设置为停用 编辑、预览、启用

推广链接管理状态（客户端后台）

状态 业务含义 触发操作 可执行的后续操作 链接访问

停推 商户标记为停止投放，仅改变后台管理状态 商户执行停推 编辑、启用（重新推广）、复制链接、预览、删除 正常访问

6.3 软删除规则

  • 删除操作为软删除，数据库保留记录。
  • 已生成并投放的推广链接不受删除影响，仍可正常访问。
  • 删除前必须弹出二次确认，明确告知商户"删除后不影响已经推出去的链接"。
  • 删除后该记录从后台列表移除，不可恢复（前端层面）。

  • 每个页面/功能小节内部固定按"业务背景 → 字段说明 → 列表交互 → 业务逻辑"四段组织。
  • 业务背景使用四行短标签（当前环节 / 页面路径 / 对下游影响 / 表格类型）。
  • 每个页面小节末尾固定保留"列表交互"，无交互时写"无交互。"。列表交互使用轻量文本表达。

8.5 单活动与多活动的简化关系

本功能中，多活动 H5 推广链接管理是单活动 H5 的扩展变体。两者的核心差异：

  • 单活动：通过 8 个字段描述一条链接，其中直跳链接仅在详情展示。
  • 多活动：去掉 B11 原文中的 8 个复杂版位字段（上方版位组合、上方平台、上方活动、上方推广位、下方版位组合、下方平台、下方活动、下方推广位），替换为上方和下方各 2 个简化字段（密令简版 + 直达链接）。

多活动模板的用户去向配置（饿了么 APP / 淘宝 APP / 美团小程序 / 饿了么小程序）保留在 SaaS 总后台模板管理中，客户端创建链接时不需要重复选择平台和活动。

8.6 待确认逻辑

1. 单活动 H5 模板的枚举值是否仅限于当前列出的 6 个（通用推广、节日活动、游戏活动、电商促销、品牌宣传、注册拉新），还是支持动态扩展？

2. 多活动 H5 模板的枚举值（双11、年货节、618、日常等）是否为固定列表，是否随 SaaS 总后台模板的启用/停用动态变化？

3. 缩略图是否支持商户自定义上传，还是固定使用模板预设图？

4. 删除后的记录是否需要在某个"回收站"页面中查看和恢复？

5. 推广链接的 shortCode 生成规则（长度、字符集、唯一性保证）是否需要与现有系统保持一致？

🔍业务背景
当前环节：③ 进入推广链接列表、④ 新建推广链接、⑤ 复制并投放、⑥ 管理推广链接、⑦ 查看详情

页面路径：客户端后台 > 推广管理 > 单活动 H5

对下游影响：商户在此完成链接的新建、编辑、停推和删除；投放的固定链接供外部渠道传播和用户访问。

表格类型：列表页


> 商户通过一个统一管理页面承载单活动 H5 推广链接的查询、新增和管理，将一个 H5 模板和一个活动组合成一条可对外投放的固定链接。新建时，商户选择一个 H5 模板，填写链接名称、密令简版、备注和直跳链接，系统生成一条固定推广链接。
⚙列表交互
交互：新增链接
业务用途：创建新的单活动推广链接。商户填写链接名称、选择 H5 模板、填写密令简版、备注和直跳链接。创建成功后，系统形成一条新的推广链接记录，并生成格式为 https://h5.example.com/p/{shortCode} 的固定访问地址。

交互：查看详情
业务用途：打开详情弹窗，展示当前链接的全部字段（含直跳链接），仅用于核对；不在详情中修改链接配置。

交互：编辑
业务用途：打开编辑弹窗，修改链接名称、H5 模板、密令简版、备注和直跳链接。编辑不改变已生成的推广链接地址。

交互：停推
业务用途：将状态为"推广中"的链接切换为"停推"，仅调整商户后台的链接管理状态，不影响推广链接访问和已投放渠道。

交互：启用
业务用途：将状态为"停推"的链接恢复为"推广中"，链接恢复正常投放管理。

交互：删除
业务用途：软删除当前推广链接记录。删除前弹出二次确认，告知商户"删除后不影响已经推出去的链接"。数据库保留记录，已分发的链接仍可正常访问。删除后列表不再展示该记录。
💡业务逻辑
模板选择范围： 只显示已启用的单活动 H5 模板。选择模板后，系统自动带出模板缩略图。

直跳链接仅详情展示： 直跳链接在新增和编辑弹窗中可填写，在详情弹窗中可查看，但不在列表表格列中展示，避免列表信息过载。

状态流转： 新建链接默认为"推广中"。推广中 → 执行停推 → 停推。停推 → 执行启用 → 推广中。任意状态均可执行软删除。

删除不中断已投放链接： 软删除仅从后台列表移除记录，已生成并投放的推广链接仍可正常访问，不影响终端用户体验。
🔍业务背景
当前环节：③ 进入推广链接列表、④ 新建推广链接、⑤ 复制并投放、⑥ 管理推广链接、⑦ 查看详情

页面路径：客户端后台 > 推广管理 > 多活动 H5

对下游影响：商户在此完成多活动链接的新建、编辑、停推和删除；投放的固定链接供外部渠道传播，用户打开后在同一页面选择上方或下方活动参与。

表格类型：列表页


> 商户通过一个统一管理页面承载多活动 H5 推广链接的查询、新增和管理。与单活动链接不同，多活动链接将一个多活动 H5 模板与上下两个版位的推广内容组合成一条可对外投放的固定链接。商户选择模板后，直接为上方版位和下方版位分别填写密令简版和直达链接，无需经过"选平台 → 选活动 → 选推广位"的复杂配置链路。
⚙列表交互
交互：新建链接
业务用途：创建新的多活动推广链接。商户填写链接名称、选择多活动 H5 模板、为上下两个版位分别填写密令简版和直达链接、填写备注。创建成功后，系统形成一条新的多活动链接记录，并生成格式为 https://h5.example.com/m/{shortCode} 的固定访问地址。

交互：查看详情
业务用途：打开详情弹窗，展示当前链接的全部字段（含上下版位的密令和直达链接），仅用于核对和复制；不在详情中修改模板或版位配置。

交互：编辑
业务用途：打开编辑弹窗，修改链接名称、多活动 H5 模板、上下版位的密令简版和直达链接、备注。编辑不改变已生成的推广链接地址。

交互：停推
业务用途：将状态为"在推"的链接切换为"停推"，仅调整商户后台的链接管理状态，不影响推广链接访问。

交互：重新推广
业务用途：将状态为"停推"的链接恢复为"在推"，链接恢复正常投放管理。

交互：复制链接
业务用途：一键复制当前固定推广链接到剪贴板，供商户对外投放或继续传播。

交互：预览
业务用途：弹窗展示当前所选模板的预览图和用户去向信息，帮助商户确认模板样式。预览展示模板静态效果，不读取当前链接的真实活动数据。

交互：删除
业务用途：软删除当前推广链接记录。删除前弹出二次确认，告知商户"删除后不影响已经推出去的链接"。数据库保留记录，已分发的链接仍可正常访问。删除后列表不再展示该记录。
💡业务逻辑
简化版位配置： 与 SaaS 总后台模板管理中复杂的"选平台 → 选活动 → 选推广位"不同，客户端创建多活动链接时，每个版位只需填写"密令简版 + 直达链接"两个字段。模板的用户去向已在 SaaS 总后台配置完成，客户端直接复用。

版位独立性： 上下版位各自独立填写密令简版和直达链接，互不影响。两个版位可以使用相同或不同的密令和链接。

模板选择范围： 只显示已启用的多活动 H5 模板。选项同时展示模板名称和上下版位的用户去向，帮助商户确认版位对应的平台。

状态流转： 新建链接默认为"在推"。在推 → 执行停推 → 停推。停推 → 执行重新推广 → 在推。任意状态均可执行软删除。

删除不中断已投放链接： 软删除仅从后台列表移除记录，已生成并投放的推广链接仍可正常访问。
