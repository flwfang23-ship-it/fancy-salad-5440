B03-A 推广路径与取链

本功能覆盖推广位列表上的推广路径展示、小程序清单弹窗、编辑抽屉中权益页推广区域（含联盟推广、内嵌H5、第三方活动三个只读镜像Tab及第三方活动路径编辑）。推广路径由权益页配置保存时系统自动生成，商户无需手动填写。当前不涉及取链清单功能和总后台操作。

1. 需求背景与目标

1.1 为什么要做

商户在权益页中配置了活动和推广内容后，每个推广位需要能指向这些内容才能生成可投放的推广链接。如果每次都需要商户手动为每个推广位填写 H5 路径和小程序路径，工作量大且容易出错。

本功能将权益页配置与推广位路径打通：权益页配置一旦保存，系统自动为所有推广位生成对应的推广路径，商户在推广位列表上即可查看和复制。同时，商户编辑推广位时可以看到该推广位对应权益页上配置了哪些活动，确认路径与活动内容一致。

改造前

商户需手动为每个推广位构造和填写推广路径
        ↓
容易出现路径错误或遗漏
        ↓
路径与权益页活动配置脱节，商户无法在一个地方确认


改造后

权益页配置保存
        ↓
系统自动为所有推广位生成小程序路径和 H5 路径
        ↓
商户在推广位列表直接查看、复制路径
        ↓
编辑推广位时可查看权益页活动镜像，确认路径与活动一致

1.2 一句话业务模型

权益页配置保存
        +
系统自动遍历所有推广位生成路径
        ↓
商户在推广位列表查看和复制路径 → 打开编辑抽屉查看权益页活动镜像 → 第三方活动可逐推广位独立编辑路径

1.3 最终目标

本功能首先要确保商户无需手动构造推广路径（路径自动生成且与权益页配置保持一致），其次让商户能在一个地方确认路径与活动的对应关系。

核心业务目标：路径自动生成，降低配置门槛

  • 路径零手动填写： 权益页配置保存后，系统自动为所有推广位生成小程序推广路径和 H5 推广路径，商户无需构造任何路径。
  • 路径与活动一致： 推广路径始终与权益页配置保持同步，商户在编辑抽屉中可直接查看该推广位对应权益页上有哪些活动。

经营效率目标：集中查看与快速复制

  • 列表直接获取路径： 商户在推广位列表即可查看和复制 H5 路径，一键查看关联的小程序清单。
  • 一个抽屉确认全部： 编辑推广位时，路径字段和三个活动 Tab 集中展示在权益页推广区域，无需在多页面间切换。

平台支撑目标：路径规则统一管控

  • H5 路径统一管理： H5 路径由权益页配置统一生成，商户不可逐推广位修改，确保所有推广位的 H5 路径指向正确。
  • 第三方路径灵活适配： 第三方活动支持统一模式（全局一致）和独立模式（逐推广位配置），适配不同投放场景。

3. 第一阶段：路径自动生成（前置条件）

3.1 阶段说明

本阶段由系统在权益页配置保存时自动执行，不需要商户操作。执行结果确保每个推广位都拥有最新的小程序推广路径和 H5 推广路径。本阶段不是商户操作步骤，而是后续列表查看和编辑抽屉管理的前置条件。

3.2 权益页配置保存时自动生成路径

流程位置

①【SaaS 系统】权益页配置保存
↓
②【SaaS 系统】遍历所有推广位，生成小程序路径和 H5 路径（当前位置）
↓
③【客户端后台】推广位列表展示最新路径

业务说明

运营或商户在权益页编辑器中完成活动配置并点击保存后，系统自动遍历当前商户的全部推广位，为每个推广位生成两条路径：

小程序推广路径
├─ 指向小程序端权益页
├─ 携带推广位标识参数
└─ 路径格式由权益页配置中的页面模板决定

H5 推广路径
├─ 指向 H5 端权益页
├─ 携带推广位标识参数
└─ 路径格式由权益页配置中的页面模板决定

除了权益页配置保存时触发，创建新推广位时系统也会为新建推广位立即生成初始路径。

已确认的处理规则

  • 路径由系统自动生成，生成逻辑基于权益页配置中的页面模板和推广位标识。
  • 生成失败时保留推广位旧路径值，不覆盖为空。
  • 推广位数量较大时，路径生成可能异步执行，前端不做阻塞等待。

对下游的影响

路径生成成功 ─────→ 推广位列表展示最新路径，商户可复制或查看
路径生成失败 ─────→ 保留旧值，路径列显示旧路径（非空不中断业务）

4. 第二阶段：推广位列表查看路径

4.1 阶段说明

本阶段承接路径自动生成的结果。商户在推广位列表中查看推广路径列，包含三项内容：推广链接缺失计数、小程序推广路径、H5 路径。商户可在此复制 H5 路径，或点击查看关联的小程序清单。

本阶段遵循管理后台阅读顺序：先介绍列表页已有记录和可执行操作，再介绍从列表发起的小程序清单弹窗。

字段 数据格式 必填条件 字段说明 下游用途

路径编辑权限

第三方活动路径编辑由活动属性控制，分为两种模式：

统一模式：路径由活动配置统一管理，所有推广位使用相同路径。路径输入框不可编辑，状态显示"统一"。如需修改，需到活动详情页操作。

独立模式：每个推广位可独立配置该活动的跳转路径。路径输入框可编辑，状态根据输入内容动态变化：

状态 视觉表现 条件
已配置 输入框有值，绿色"已配置"标签 商户已为该推广位填写了独立路径
使用默认 输入框为空（placeholder 显示默认路径），灰色"使用默认"标签 未填独立路径，但活动有默认路径兜底
缺失 输入框红色边框，红色"缺失"标签 未填独立路径，且活动无默认路径兜底

Tab 标签右侧显示 Badge 数字，统计当前处于"缺失"状态的活动数量。此数字与推广位列表"推广链接"列的计数一致。

编辑独立模式路径 活动为独立模式 输入内容后状态标签实时更新，Badge 计数同步刷新 —

6. 关键业务规则

6.1 路径生成与同步

  • 权益页配置保存时，系统自动遍历全部推广位重新生成小程序路径和 H5 路径。
  • 新建推广位时，系统立即为新推广位生成初始路径。
  • 路径生成失败时保留旧值，不覆盖为空，确保已投放链接不中断。

6.2 H5 路径只读保护

  • H5 路径由权益页配置统一管理，商户不可在推广位编辑抽屉中修改。
  • 如需修改 H5 路径，应在权益页配置中操作，系统自动同步到所有推广位。

6.3 三个 Tab 表数据来源

  • 联盟推广、内嵌 H5、第三方活动三个 Tab 的数据完全来源于权益页配置，是只读镜像（第三方活动路径除外）。
  • 权益页配置变更后，所有推广位编辑抽屉中的三个 Tab 内容自动同步更新。
  • 商户在编辑抽屉中仅查看活动信息，不能增删活动或修改活动属性。

6.4 第三方活动路径编辑规则

  • 活动属性决定路径是否可逐推广位编辑（统一模式或独立模式）。
  • 统一模式下路径全局一致，不可在推广位层面修改。
  • 独立模式下路径可逐推广位配置，状态根据是否有值、是否有默认路径兜底动态判定。
  • 缺失计数 = 无默认路径且未配置独立路径的第三方活动数量，同时在列表"推广链接"列和编辑抽屉第三方活动 Tab 标签上展示。

6.5 小程序清单数据范围

  • 小程序清单弹窗仅展示当前推广位关联的小程序，不展示全量小程序列表。
  • 推广位无关联小程序时，弹窗显示空状态，"查看小程序路径"按钮不出现。

8.2 正文组织原则

  • 正文按业务实际发生顺序展开（系统自动生成 → 商户查看 → 商户编辑），不按总后台/客户端分别集中成章。

8.3 泳道和参与方识别

8.5 术语与口径

  • 全文统一使用"推广位""推广路径""权益页配置""联盟推广活动""内嵌 H5 活动""第三方活动"。
  • "推广链接缺失计数"统一口径：统计第三方活动中无默认路径且未配置独立路径的活动数量。
  • "统一模式"指 allowIndividualEdit=false，路径由活动全局配置。"独立模式"指 allowIndividualEdit=true，路径可逐推广位编辑。
  • "权益页配置"指商户在权益页编辑器中保存的页面配置数据，包含活动信息和页面模板。
  • 三个 Tab 的数据来源统一描述为"权益页配置"，不区分 availableActivities / thirdPartyActivities 等技术字段名。

8.6 不得混淆

  • 第三方活动路径"缺失"不等于推广位不可用——联盟活动和内嵌 H5 活动仍可正常推广。
  • H5 路径只读不等于 H5 路径不能修改——修改入口在权益页配置，不在推广位编辑抽屉。
  • 三个 Tab 是只读镜像不等于第三方活动路径不能编辑——第三方活动在独立模式下路径可编辑。
  • 权益页配置变更不等于推广位路径立即更新——路径同步在权益页配置保存时触发。
  • 编辑抽屉中的活动展示不等于活动管理——增删活动、修改活动属性需到权益页配置或活动管理模块操作。
  • 小程序清单弹窗展示的是关联小程序，不等于全量已注册小程序。
