B08-G 双套小程序默认模板（VIP分级）

状态：方案设计 | 日期：2026-07-07 | 类型：功能新增 依赖：B01（商户注册）、B08-D（代码审核发布）

一、需求背景

系统目前只有 1 套 小程序默认模板（代码模板库 + 默认权益页布局），所有商户注册后看到的模板是一样的。

现在需要支持 2 套 默认模板：

商户类型 模板套系 适用场景
普通商户 标准版模板（Standard） 自主注册 / 普通邀请注册
VIP 商户 VIP 专享模板（VIP） 通过 VIP 链接注册的商户

核心原则：做轻——代码写死 2 套模板，总后台和客户端都不增加配置项，纯逻辑判断。

二、VIP 商户识别机制

2.0 VIP 链接标识（链路入口）

VIP 商户的识别必须从注册入口开始就有据可查。VIP 邀请链接携带一个可追溯的标识参数，注册时捕获并写入商户数据。

2.0.1 VIP 链接格式

https://{domain}/register?channel=vip&inviteCode=VIP20260707001
                         └──────┬──────┘ └─────────┬─────────┘
                          渠道标识=vip            邀请码（唯一，可追溯）
参数 必填 说明
channel 是 固定值 vip，区分普通邀请链接
inviteCode 是 VIP 邀请码，唯一编号，用于追溯"这个商户是通过哪条 VIP 链接进来的"

2.0.2 注册流程捕获

用户点击 VIP 链接
      │
      ▼
注册页 URL 携带 ?channel=vip&inviteCode=VIP20260707001
      │
      ▼
前端解析 URL 参数：
  const urlParams = new URLSearchParams(window.location.search);
  const channel = urlParams.get('channel');       // 'vip'
  const inviteCode = urlParams.get('inviteCode'); // 'VIP20260707001'
      │
      ▼
提交注册时，将标识写入商户数据：
  merchant.source     = 'VIP邀请注册'
  merchant.inviteCode = 'VIP20260707001'   ← 新增字段，可追溯
  merchant.channel    = 'vip'              ← 新增字段
      │
      ▼
后端 / Mock 数据持久化，source 字段锁定

2.0.3 代码如何查到

// 方式一：注册页入口 —— 从 URL 读取 VIP 标识
function getVipParamsFromUrl() {
  var params = new URLSearchParams(window.location.search);
  return {
    channel:    params.get('channel')    || '',
    inviteCode: params.get('inviteCode') || ''
  };
}

// 方式二：全局 —— 判断当前商户是否 VIP
function isVipMerchant(merchant) {
  return merchant && (
    merchant.source === 'VIP邀请注册' ||
    merchant.channel === 'vip'
  );
}

// 方式三：模板选择 —— 根据 VIP 标识返回对应套系
function getTemplateSetForMerchant(merchant) {
  return isVipMerchant(merchant)
    ? VIP_DEFAULT_TEMPLATES
    : STANDARD_DEFAULT_TEMPLATES;
}

2.0.4 可追溯性

商户数据中新增两个字段，确保 VIP 来源全程可查：

// 商户对象扩展
{
  id: 'M021',
  companyName: '深圳VIP精选科技有限公司',
  source: 'VIP邀请注册',          // 原有字段，新增枚举值
  inviteCode: 'VIP20260707001',  // ← 新增：VIP邀请码，关联到具体VIP链接
  channel: 'vip',                // ← 新增：渠道标识
  ...
}

总后台商户列表可以看到 source 和 inviteCode，运营可以追溯"这个 VIP 商户是通过哪条邀请链接进来的"。

2.1 判定依据

商户数据中已有 source 字段（当前值："自主注册" / "邀请注册"）。新增一种来源 + 两个辅助字段：

// 商户 source 字段扩展
source: '自主注册'       // 普通商户 → 标准版模板
source: '邀请注册'       // 普通商户 → 标准版模板（channel 为空或非 vip）
source: 'VIP邀请注册'    // VIP商户  → VIP专享模板  ← 新增（channel=vip 时自动写入）

2.2 判定逻辑（伪代码）

// 双条件判定：source 优先，channel 兜底
function isVipMerchant(merchant) {
  return merchant && (
    merchant.source === 'VIP邀请注册' ||
    merchant.channel === 'vip'
  );
}

function getTemplateSetForMerchant(merchant) {
  return isVipMerchant(merchant) 
    ? VIP_DEFAULT_TEMPLATES    // VIP 专享模板套系
    : STANDARD_DEFAULT_TEMPLATES; // 标准版模板套系
}

2.3 影响范围

  • VIP 链接生成时：运营在总后台生成 VIP 邀请链接，系统自动分配 inviteCode（格式 VIP + 日期 + 序号）
  • 新商户注册时：前端解析 URL 参数 → 写入 source / channel / inviteCode → 根据 source 决定初始化哪套模板
  • 已有商户：不受影响，维持现状
  • 商户来源不可变更：注册后 source / channel 字段锁定，不会出现中途切换模板套系的问题
  • 追溯查询：总后台商户列表可按 source='VIP邀请注册' 筛选，按 inviteCode 追溯到具体 VIP 链接

六、不做什么

  • ❌ 总后台不做：不增加"模板归属配置"功能，不增加"VIP模板管理"页面
  • ❌ 客户端不做：商户不能自己选择用哪套模板
  • ❌ 不动态化：模板列表不通过接口获取，代码里硬编码
  • ❌ 不存数据库：不建 vip_template_config 表，纯前端逻辑
  • ❌ 不改变现有商户：只对新注册的 VIP 商户生效

七、数据流示意

用户点击 VIP 邀请链接
    │  URL: ?channel=vip&inviteCode=VIP20260707001
    ▼
注册页解析 URL 参数
    │  getVipParamsFromUrl() → { channel:'vip', inviteCode:'VIP20260707001' }
    ▼
提交注册，写入商户数据
    │  source='VIP邀请注册'  channel='vip'  inviteCode='VIP20260707001'
    ▼
商户创建完成，source 锁定
    │
    ├─ source = '自主注册' / '邀请注册'
    │     └─→ isVipMerchant() → false
    │         ├─→ 加载 standardMiniappTemplates (10个)
    │         └─→ 加载 standardDefaultStyleConfig (4组件)
    │
    └─ source = 'VIP邀请注册'
          └─→ isVipMerchant() → true
              ├─→ 🏷️ 打上「VIP」标签（商户 + 名下小程序均标记）
              ├─→ 加载 vipMiniappTemplates (13个)
              └─→ 加载 vipDefaultStyleConfig (6组件)

八、关键函数签名

/**
 * 判断商户是否为VIP
 * @param {Object} merchant - 商户对象
 * @returns {boolean}
 */
function isVipMerchant(merchant) {
  return merchant && merchant.source === 'VIP邀请注册';
}

/**
 * 根据商户类型获取对应的代码模板列表
 * @param {Object} merchant - 商户对象（可选，不传返回标准版）
 * @returns {Array} 模板列表
 */
function getMiniappTemplatesForMerchant(merchant) {
  var D = window.AdminMockData;
  if (!D) return [];
  return isVipMerchant(merchant) 
    ? D.vipMiniappTemplates 
    : D.standardMiniappTemplates;
}

/**
 * 根据商户类型获取对应的默认权益页布局
 * @param {Object} merchant - 商户对象（可选，不传返回标准版）
 * @returns {Object} 默认布局配置
 */
function getDefaultStyleConfigForMerchant(merchant) {
  var D = window.AdminMockData;
  if (!D) return null;
  return isVipMerchant(merchant) 
    ? D.vipDefaultStyleConfig 
    : D.standardDefaultStyleConfig;
}
