1.1 为什么要做

商户推广单个外卖活动时，需要获得与指定推广位绑定的推广内容，并将其投放到企微、社群、朋友圈等渠道。

原有活动取链能力可以临时生成推广内容，但商户缺少一个统一管理历史单活动链接的入口。已经生成的链接分散在活动清单或取链操作中，不方便后续查找、预览、维护备注和区分是否仍在推广。

本功能将"单活动、单推广位、单活动 H5 模板"组合成一条固定推广链接，并将手动新建和活动清单取链形成的记录汇总到同一列表中管理。

改造前后对比
改造前

进入活动清单
        ↓
选择推广位并临时取链
        ↓
复制后自行投放
        ↓
历史链接缺少统一管理入口


改造后

单活动 H5 模板 + 可推广活动 + 商户推广位
        ↓
单活动 H5 管理页新建 / 活动清单手动取链
        ↓
形成固定单活动 H5 链接
        ↓
统一预览、编辑和切换推广状态
        ↓
C 端用户打开链接并参与活动

1.2 一句话业务模型

SaaS 总后台提供的已启用单活动 H5 模板
        +
一个可推广活动
        +
当前商户的一个有效推广位
        ↓
形成一条固定单活动 H5 链接
        ↓
C 端展示该活动的推广内容

商户在新建时可以一次选择多个推广位。系统按"一个活动 × 一个推广位"拆分，每个推广位分别形成一条独立链接。

1.3 最终目标

  • 独立投放：让每个推广位形成独立、可持续投放的活动链接。
  • 正确归因：让推广过程可以正确归因并形成收入。

2.2 阶段划分与阅读说明

后续正文按照业务实际发生顺序线性展开，不按操作端分别集中介绍。根据当前业务闭环，可划分为：

  1. 第一阶段：模板与推广基础准备（主要参与方：SaaS 总后台）：SaaS 总后台依次创建单活动 H5 模板、创建联盟活动并为活动配置模板。单活动 H5 链接形成前，必须先完成这三项准备，商户也需要准备好可供选择的推广位。核心准入规则是只有已配置单活动 H5 模板的活动，客户取链时才可看到 H5 选项。
  2. 第二阶段：单活动链接形成与管理（主要参与方：客户端后台）：链接通过手动新建或活动清单取链形成，两条路径在形成记录后汇合进入统一列表管理。本阶段承接已准备好的模板、活动和推广位，由客户端后台形成并管理链接。
  3. 第三阶段：C 端访问与活动参与（主要参与方：C 端用户）：商户投放固定链接后，C 端用户无需登录即可打开页面。页面根据链接确定模板、活动和推广位，展示该活动当前可用的推广内容，用户可复制口令或进入活动参与。

6.1 跨阶段业务规则

模板→活动→取链的准入链：只有 SaaS 总后台启用了单活动 H5 模板、活动已配置该模板后，客户取链时才可看到 H5 选项。创建活动不等于客户取链时可见 H5 选项，三者存在顺序依赖。

链接形成后不可修改核心组合：活动、模板和推广位在链接形成后不直接修改；编辑仅用于修改备注。如需更换活动、模板或推广位，应创建新链接。

推广状态与 C 端访问分离："推广中、已停推"是商户后台的链接管理状态，不代表活动本身的上架状态，也不代表 C 端页面是否可访问。停推后 C 端链接仍可正常访问。

6.2 业务分支与汇合规则

  • 手动新建路径：在单活动 H5 列表页主动新建，客户自行选择平台、活动、模板和推广位。
  • 活动清单取链路径：活动只有已配置单活动 H5 模板，取链时才显示 H5 选项；使用活动已配置的模板，不另行选择。
  • 汇合点：两条路径在"形成单活动 H5 链接记录"后汇合，后续在单活动 H5 链接列表中统一展示和管理，字段、状态和操作规则保持一致。

  • 重新推广：将推广状态从"已停推"恢复为"推广中"。固定链接不变。
⚙业务逻辑

一条链接只对应一个推广位：每条链接固定对应一个活动、一个模板和一个推广位。多选推广位是批量操作方式，不改变单条链接粒度。

模板与活动组合规则：只使用单活动 H5 模板，创建时模板必须启用。

编辑范围限制：链接形成后活动、模板和推广位不直接修改；编辑仅用于修改备注。

固定链接与内容更新：链接形成后作为固定入口长期投放，C 端按绑定关系读取当前可用内容。

推广状态与 C 端访问分离：停推后 C 端链接仍可正常访问。

📝业务背景

C 端单活动 H5 展示页是用户打开固定链接后看到的推广页面。使用既有 C 端展示页，B14 不新增页面模板。

当前环节：⑦ 打开链接、⑧ 查看活动推广内容、⑨ 复制口令或参与活动

页面路径：C 端 > 口令 H5 展示页

⚙业务逻辑

页面状态规则：根据链接、活动、推广位和推广内容的可用性，正常展示活动内容或展示对应的状态提示。

后台状态隔离：客户端后台的"已停推"标记不向 C 端用户展示，商户后台管理状态不直接暴露给 C 端。

内容读取时机：C 端按链接绑定的商户、活动和推广位读取当前可用的活动口令与推广内容。
