B1 首页内容流三个 tab 共用一套骨架，只有数据源与排序不同
1-1 首页 · 美食 tab 页面·首页/美食
1
首页 · 美食 tab
属性：页面
关键字段：画面 · 顶栏「↻ 刷新图标 / 种草 / 发现 / 美食」· 分类栏「全部」 · 双列瀑布流 · 卡片只有 5 个字段：主图 / 标题 / 发布人 / 地点（无则省略）/ 点赞数
结果：默认落地美食 tab，按发布时间倒序；点卡片进详情
下一环：切「发现」tab → 1-2；底部进「我的 / 工具」→ 3-1 / 4-1
顶部 tab 顺序沿用原稿（种草 / 发现 / 美食）只改名改功能；首页不挂额外按钮，入口全收进 tabbar 与卡片。
限制：分类栏默认「全部」，切换分类只过滤当前 feed，不单独出帧。
限制：地点取自后台配置的地点文案，只显示地点名、不显示距离；未配置地点的帖子胶囊整块不显示、封面不留空位。
限制：左上角刷新图标仅刷新当前 tab 当前分类的 feed 接口，点后图标转圈、转圈期间不可重复点击，拉取完成回到常规态。
1-2 首页 · 发现 tab 页面·首页/发现
2
首页 · 发现 tab
属性：页面
关键字段：画面 · 同骨架 · 卡片顺序打乱 · 封面左下角地点胶囊随帖同步
结果：数据源不变，仅重排出新顺序，制造「逛」的感觉
下一环：切「种草」tab → 1-3
发现不引入新内容源、不改卡片结构，纯排序差异，避免用户以为进了另一个频道。
1-3 首页 · 种草 tab 页面·首页/种草
3
首页 · 种草 tab
属性：页面
关键字段：数据源 · 我的收藏集合 · 卡片带「已收藏」标 · 封面左下角地点胶囊
结果：只展示我收藏过的帖子，与详情页「收藏」按钮同源
下一环：有收藏 → 点卡片进 2-2；无收藏 → 1-4 空态
「关注」改成「种草」后，这个 tab 不再是订阅流，而是用户自己的收藏夹，直接复用收藏数据；因为已经是收藏夹，这一页取消分类栏。
1-4 首页 · 种草空态 页面·首页/种草-空
4
种草空态
属性：页面
关键字段：画面 · 空态图标 · 文案「还没有收藏的帖子」· 唯一按钮「去逛逛美食」
结果：收藏数为 0 时展示，不出现分类栏、不出现任何帖子占位
下一环：点「去逛逛美食」→ 回 1-1 美食 tab
新用户注册后收藏必定为空，这是高频必现路径，必须单独出帧；空态只留一条出口，避免用户在空页面里打转。
限制：空态只在收藏数 = 0 时出现；「我的 → 种草」进入同样落这一帧。
