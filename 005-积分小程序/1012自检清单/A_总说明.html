目的 一句话
本清单是积分小程序后续开发的自检基线：新增 / 迭代任何积分活动，必须对照 B 后台 4 项 + C 端 4 项逐条打勾，没勾不允许上线。
自检清单总览 点卡片底部入口进入对应清单

全局配置

→ 进入 C 端自检清单
使用规则 3 条
每新增一个积分活动：先建后台活动卡片 + 配全局积分值 →再出 C 端 4 件物料（分享图 / 落地页 / 缺省页 / 流水枚举） →最后核对流水与卡片同名。
活动开关关闭后，必须验证 C 端三停：弹窗不触发 · 页面入口隐藏 · 积分不赠送。
流水枚举值必须与后台活动卡片名称完全一致，不允许别名、不允许简称、不允许大小写差异。
